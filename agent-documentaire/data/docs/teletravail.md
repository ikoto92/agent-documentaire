# Charte de télétravail – NovaTech (entreprise fictive)

## Éligibilité
Le télétravail est ouvert à tous les salariés après la fin de leur période d'essai. Les alternants y ont droit dans les mêmes conditions, avec l'accord de leur tuteur.

## Nombre de jours
Chaque salarié peut télétravailler jusqu'à 2 jours par semaine. Les jours de télétravail sont fixés avec le manager et déclarés dans l'outil « Kiosque ». Le lundi est un jour de présence obligatoire pour toutes les équipes.

## Équipement
NovaTech fournit un ordinateur portable, un écran et un casque. Une indemnité de télétravail de 2,50 euros par jour télétravaillé est versée avec le salaire, dans la limite de 40 euros par mois.

## Sécurité
Le VPN de l'entreprise doit être activé pour tout accès aux outils internes. Il est interdit de travailler sur des données clients depuis un réseau Wi-Fi public.
